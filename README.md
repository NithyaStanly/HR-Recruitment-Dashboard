# HR Recruitment Dashboard | Microsoft Excel

## Project Overview
An HR analytics project developed using Microsoft Excel to analyse employee demographics, workforce distribution, recruitment trends and employee performance.

## Objectives
- Analyse employee demographics and workforce distribution.
- Examine recruitment sources and hiring trends.
- Analyse employee salaries and performance.
- Explore employee satisfaction and absenteeism.
- Present HR insights through an Excel dashboard.

## Tools & Techniques
- Microsoft Excel
- PivotTables
- Excel Charts
- Data Analysis
- Data Visualisation

## Key Analysis Areas
- Employee demographics
- Department-wise workforce distribution
- Salary and performance analysis
- Employee satisfaction
- Absenteeism
- Recruitment sources

## Project File
- `HRDataset_v14.xlsx` – Completed HR Recruitment Dashboard.

## Purpose
To apply Excel data analysis and visualisation techniques to explore HR data and present meaningful workforce insights.
